eb-shard-weights: build an `eb-stack stack shard --weights` table from run durations.

  eb-shard-weights (--result FILE... | --summary FILE... | --log-root DIR [--last N])
                   [--target NAME] [--existing FILE] [--min-samples N]
                   [--mode max|latest|mean] [--out FILE]

Reads `duration_seconds` of succeeded `build` lines from `eb-pipeline` result
or summary files (or the newest runs under `--log-root`), maps each easyconfig
to `Name/Version`, and writes sorted `MODULE<TAB>SECONDS` lines rounded up to
whole seconds for `eb-stack stack shard --weights` and `[shards] weights`.

When no input option is present, `EB_PIPELINE_RESULT` supplies one result
file. `EB_PIPELINE_TARGET` supplies `--target`. A command-line option wins.

Failed, refused, pending, skipped, and source-fetch lines are ignored.
`--existing` preserves modules not seen in the new runs and updates the rest
according to `--mode` (`max`, `latest`, or `mean`; default `max`).
`--min-samples N` updates only modules with at least N selected observations.
An under-sampled module keeps its existing weight or remains absent.
