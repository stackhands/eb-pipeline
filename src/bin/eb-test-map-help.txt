eb-test-map: name the tests that cover the easyconfigs in a build list.

  eb-test-map --map FILE --list FILE [--toolchain NAME]... [--allow-unmapped]

FILE of --map has one software name and one test name per line.
A line of --list is an easyconfig, or a path to one. The software name is
the part of the file name before the version. GCC, GCCcore, foss, gfbf,
gomkl, gompi, iimpi, intel and intel-compilers have no test of their own.
--toolchain names another. Any other software with no row exits 2, unless
--allow-unmapped is set, and then nothing is printed. The test names go
to stdout, one per line, sorted, each once.
