eb-cvmfs: run a cache synchronization inside one CVMFS transaction.

  eb-cvmfs [--dry-run] REPOSITORY -- COMMAND [ARG...]

Checks that REPOSITORY is not already in a transaction, starts
`cvmfs_server transaction REPOSITORY`, and runs COMMAND with its arguments.
If COMMAND succeeds, publishes REPOSITORY. If COMMAND fails or cannot start,
aborts it with `cvmfs_server abort -f REPOSITORY` and returns COMMAND's exit
status.

This command only brackets the configured synchronization. It does not build
or package tarballs. `--dry-run` prints the check, transaction, sync, publish,
and failure-abort commands without running them.
