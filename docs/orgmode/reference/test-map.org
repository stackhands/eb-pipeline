* The test map

=eb-test-map= reads a map and a build list and prints the test names that cover the applications in the list.

#+begin_example
eb-test-map --map FILE (--list FILE | --result FILE) [--toolchain NAME]... [--allow-unmapped] [--format FORMAT]
#+end_example

| Option | Meaning |
|--------+---------|
| =--map FILE= | One software name and one test name per line, separated by whitespace. A line that starts with =#= is a comment. Required. |
| =--list FILE= | Build list file. With =.yml= or =.yaml= it is read as an EasyBuild easystack and its =easyconfigs= entries become the list lines. |
| =--result FILE= | Result JSON written by =eb-pipeline run --result=. Only lines with =status = "success"= are mapped to tests. |
| =--toolchain NAME= | A software name that needs no test, besides the built-in toolchains. |
| =--allow-unmapped= | Print the tests that exist and exit 0 when an application has no row. Without it, that application prints nothing and exits 2. |
| =--format FORMAT= | =text= (default): one test name per line. =reframe=: one selector per line as =-n ^...$=, with regex characters escaped so the name stays literal. |

The built-in toolchains are =GCC=, =GCCcore=, =foss=, =gfbf=, =gomkl=, =gompi=, =iimpi=, =intel= and =intel-compilers=.

Pass one of =--list= or =--result=.
Stdout is the test names, sorted, each once; =--format= chooses how each line is written.
Messages go to stderr.

Exit 0 means every application in the list has a test, or =--allow-unmapped= was set. Exit 2 is a missing file, a bad line, or an application with no test.

[[file:../howto/run-tests-for-what-you-built.org][Run the tests that cover what you built]] uses it as the checks command.
