* The plan and result files

=eb-pipeline plan= writes a proposed plan, =eb-pipeline run --plan-out FILE= writes the plan computed by that invocation, and =eb-pipeline run --result FILE= writes its result.
Both are objects in JavaScript Object Notation (JSON), with the keys of every object in sorted order, and both have =schema_version= 1.
The examples on this page come from =docs/examples/files.sh=, which plans and runs a two-line list on a site with the =local= scheduler, kept logs and rotation, with stand-ins for =eb= and =eb-keep-logs= that print their arguments.

** The plan file

=plan --out FILE= writes a proposed plan to =FILE=, and =plan= without =--out= prints it.
=run --plan-out FILE= writes the plan after the run computes it, before it starts any phase command.
A dry run writes the plan too.
The file uses the run's actual default run id and log stamp.
A real run includes its input attestation when =[attest]= is enabled; a dry run does not append an attestation.
An existing file is atomically replaced after the complete plan is written and synced to a temporary sibling.
If the plan cannot be written, no phase command starts and the run exits 1.
A plan holds every phase, planned or not, in the order a run goes through them, and every command a run would start, with its whole argument vector and environment.

#+begin_src bash
eb-pipeline plan --site site.toml --list build.list --target cpu --build-type production \
    --run-id nightly --log-stamp 20261117_090000 --out plan.json
cat plan.json
#+end_src

| Key              | Type    | Meaning                                                                                                                  |
|------------------+---------+--------------------------------------------------------------------------------------------------------------------------|
| =build_type=     | string  | The build type.                                                                                                          |
| =deselected=     | array   | The lines that the target's =[targets.select]= leaves out; only when there are some.                                     |
| =input_attestation= | object | The record hash and the RFC 9162 inclusion proof, when =[attest]= is enabled. Absent otherwise. =record_sha256= is the SHA-256 of the canonical input record. =proof= is the JSON object =rfc9162-sidecar prove= wrote. |
| =kind=           | string  | =plan=.                                                                                                                  |
| =lines=          | integer | The number of lines of the list, without blank lines and comments.                                                       |
| =list=           | string  | The build list as =--list= names it, or the absolute package-plan bundle directory.                                     |
| =log_dir=        | string  | =LOG_ROOT/LOG_STAMP/TARGET=, where the run writes its logs.                                                              |
| =package_plan_digest= | string | The SHA-256 of =package.plan.json=, only with =--package-plan=.                                                      |
| =phases=         | array   | Every phase, in the order a run goes through them.                                                                       |
| =run_id=         | string  | The run id, =<run-id>= without =--run-id=.                                                                               |
| =schema_version= | integer | =1=.                                                                                                                     |
| =selected=       | integer | The number of lines that =[targets.select]= keeps; only with that table.                                                 |
| =selected_list=  | string  | =LOG_DIR/selected-TARGET.list=, the file a run writes the kept lines to for =stack shard=; only with =[targets.select]=. |
| =site=           | string  | =site.name=.                                                                                                             |
| =target=         | string  | The name of the target.                                                                                                  |

Where a run reads a value when it starts, the plan shows a stand-in: =<run-id>= and =<log-stamp>= without =--run-id= and =--log-stamp=, =${NAME}= for a variable that the site file names, and =<exit-status>= for the status of the line that failed.

*** Each entry of =phases=

| Key        | Type   | Meaning                                                                                                                          |
|------------+--------+----------------------------------------------------------------------------------------------------------------------------------|
| =commands= | array  | The commands of the phase, in the order a run starts them.                                                                       |
| =env=      | object | The environment of the phase, which each of its commands gets.                                                                   |
| =name=     | string | =preflight=, =licences=, =shard=, =sources=, =admission=, =build=, =checks=, optional =verification=, =caches= or =logs=.        |
| =reason=   | string | Why the phase is not planned; only then.                                                                                         |
| =role=     | string | The role whose launch arguments its commands take, such as =build= or =short=; only for a phase that has one.                    |
| =status=   | string | =planned=, =not configured=, or =refused= for an admission that =admission.required= asks for when the site file cannot give it. |

*** Each entry of =commands=

| Key    | Type            | Meaning                                                                                                                   |
|--------+-----------------+---------------------------------------------------------------------------------------------------------------------------|
| =argv= | array of string | The whole command: the route, the launch line and the module wrapper when there are any, then the tool and its arguments. |
| =env=  | object          | Variables set over the phase environment for this command; only when there are some.                                      |
| =name= | string          | =probe:TOOL=, =shard=, =fetch:STEM=, =admit:UNIT=, =build:STEM=, =keep-failed:STEM=, =check=, =cache= or =rotate=.        |
| =note= | string          | What to know about the command, such as what its exit statuses mean; only when there is something.                        |

Each =argv= element is one subprocess argument, so spaces and non-ASCII
characters stay in that element without shell quoting.
For an easyconfig name that starts with =-=, all EasyBuild options precede
=--= and the original name follows it. The plan's =list= and the result's
=easyconfig= retain the original name.

=STEM= is the easyconfig file name without =.eb=, with =.2=, =.3= and so on added when the list repeats a line.
=UNIT= is =all= for the whole list, or =cpu-prerequisites=, =prelude= or the name of a shard with a shard plan.
A =probe:TOOL= command runs the =--version= of a tool that has a =min_version=.

*** Each entry of =deselected=

| Key          | Type   | Meaning                                                          |
|--------------+--------+------------------------------------------------------------------|
| =easyconfig= | string | The easyconfig of the line.                                      |
| =unit=       | string | =all=: the selection reads the whole list, before =stack shard=. |

** The result file

=run --result FILE= writes it when the run ends, and =run= without =--result= writes none.
The complete result is written and synced to a temporary sibling before it atomically replaces an existing =FILE=.
=run --dry-run= writes none either, and neither does a run that an error in its input stops before it starts, such as an invalid site file, an unknown target, a list that cannot be read or a tool below its =min_version=: those exit 2, or 78 when only the licence gate fails, and leave an existing =FILE= as it was.
Read the exit status before the file.

#+begin_src bash
eb-pipeline run --site site.toml --list build.list --target cpu --build-type production \
    --run-id nightly --log-stamp 20261117_090000 --result result.json
#+end_src

| Key                | Type    | Meaning                                                                                                                |
|--------------------+---------+------------------------------------------------------------------------------------------------------------------------|
| =admission=        | array   | The admission of each unit that went through it, in order.                                                             |
| =build_type=       | string  | The build type.                                                                                                        |
| =counts=           | object  | The number of lines with each status, for the statuses that some line has. A deselected line counts for none.          |
| =deselected=       | array   | The lines that the target's =[targets.select]= left out, as in the plan; only when there are some.                     |
| =duration_seconds= | number  | How long the run took, from its start to the writing of the result file, in seconds to the millisecond.                |
| =ended_at=         | string  | When the run ended, in Coordinated Universal Time (UTC): the date, the time to the nanosecond and the offset =+00:00=. |
| =exit_code=        | integer | The exit status of the run.                                                                                            |
| =input_attestation= | object | The record hash and the RFC 9162 inclusion proof, when =[attest]= is enabled. Absent otherwise. Same object as on the plan. |
| =input_digest=     | string  | The SHA-256 of the file =eb-stack stack order --hashes-out= wrote, when =[resume]= is enabled. Absent otherwise.        |
| =interrupted_by=   | string  | =SIGINT= or =SIGTERM=, when a signal stopped the run.                                                                  |
| =kind=             | string  | =result=.                                                                                                              |
| =lines=            | array   | Every line the run reached, in that order.                                                                             |
| =list=             | string  | The build list as =--list= names it, or the absolute package-plan bundle directory.                                   |
| =log_dir=          | string  | =LOG_ROOT/LOG_STAMP/TARGET=, where the run wrote its logs.                                                             |
| =package_plan_digest= | string | The SHA-256 of =package.plan.json=, only with =--package-plan=.                                                     |
| =message=          | string  | The error that stopped the run, when one did.                                                                          |
| =not_configured=   | array   | The phases that the site file leaves out, in pipeline order.                                                           |
| =phases=           | array   | Every phase the run reached, in pipeline order from =preflight= to =logs=.                                             |
| =run_id=           | string  | The run id.                                                                                                            |
| =schema_version=   | integer | =1=.                                                                                                                   |
| =sharded=          | boolean | Whether the lines were built in the units of a shard plan.                                                             |
| =site=             | string  | =site.name=.                                                                                                           |
| =started_at=       | string  | When the run started, in the same form as =ended_at=.                                                                  |
| =target=           | string  | The name of the target.                                                                                                |

*** Each entry of =lines=

| Key                | Type    | Meaning                                                                                                                                                           |
|--------------------+---------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =duration_seconds= | number  | How long the line's command ran, in seconds to the millisecond: its build, or the prefetch of its sources when that failed; absent for a line that did not start. |
| =easyconfig=       | string  | The easyconfig of the line.                                                                                                                                       |
| =exit_code=        | integer | The exit status the line counts as; absent for a line that did not run.                                                                                           |
| =log=              | string  | The log of the line's command.                                                                                                                                    |
| =note=             | string  | Why the line came to its status, when that needs saying. A line that went through eb-staged-rebuild has one, whatever its status.                                 |
| =outputs=          | array   | Module files a successful line left, when =[resume]= recorded them. A resumed line copies the prior list. Absent when empty.                                        |
| =phase=            | string  | =build=, or =sources= when the prefetch of its sources failed.                                                                                                    |
| =status=           | string  | =success=, =failed=, =refused=, =pending= or =skipped=.                                                                                                           |
| =translated_from=  | integer | The command's own exit status, when =exit_code= translates it, as 78 does eb-staged-rebuild's 2.                                                                  |
| =unit=             | string  | The unit of the line: =all=, =cpu-prerequisites=, =prelude= or the name of a shard.                                                                               |

| Status    | Meaning                                                                                                               |
|-----------+-----------------------------------------------------------------------------------------------------------------------|
| =success= | Its command exited 0, and the run received no signal before it recorded the line.                                     |
| =failed=  | Its command or source prefetch failed, or a signal stopped the run while the line was active. An active line stopped by =SIGINT= or =SIGTERM= has exit status 130 or 143, even when its command handled the signal and exited 0. |
| =refused= | =eb-staged-rebuild run= refused it, with exit 2.                                                                      |
| =pending= | =eb-staged-rebuild run= exited 75: a ledger event it requires is pending.                                             |
| =skipped= | It did not run: admission refused its unit or an earlier one, a signal stopped the run first, or =[resume]= skipped a unit whose prior lines succeeded and whose module files are still present. The note says which. |

*** Each entry of =phases=

| Key                | Type    | Meaning                                                                                                                                 |
|--------------------+---------+-----------------------------------------------------------------------------------------------------------------------------------------|
| =duration_seconds= | number  | How long the commands of the phase ran, added up, in seconds to the millisecond; absent for a phase that ran none, such as =preflight=. |
| =exit_code=        | integer | The exit status behind the status, when there is one.                                                                                   |
| =name=             | string  | The phase.                                                                                                                              |
| =note=             | string  | Why the phase came to its status, when that needs saying.                                                                               |
| =status=           | string  | What the phase came to.                                                                                                                 |

=admission= and =build= take turns unit by unit, and the =duration_seconds= of each counts only its own commands.
That of =logs= counts =eb-keep-logs failed= after a failed line as well as =eb-keep-logs rotate=.

| Status           | Meaning                                                                                                                                                                                                                                           |
|------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =ok=             | The phase did its work.                                                                                                                                                                                                                           |
| =failed=         | A command of the phase failed, or, for =build=, a line did.                                                                                                                                                                                       |
| =refused=        | Something the phase needs is missing, such as a variable that the site file names, and the run stopped; for =build=, also a line or unit was refused and none succeeded or failed.                                                                |
| =skipped=        | The phase did not do its work, and the note says why: for =build=, admission refused before any line started; for =caches=, the build did not finish cleanly; for =logs=, another run held the rotation lock, or =eb-keep-logs rotate= exited 75. |
| =unsharded=      | =shard= only: =stack shard= exited with =shards.planner_exit_unsharded=, and the list built as one unit.                                                                                                                                          |
| =interrupted=    | A signal stopped the run in this phase.                                                                                                                                                                                                           |
| =not configured= | The site file leaves the phase out.                                                                                                                                                                                                               |

*** Each entry of =admission=

| Key         | Type    | Meaning                                           |
|-------------+---------+---------------------------------------------------|
| =attempts=  | integer | How many times =stack admit= ran for the unit.    |
| =last_json= | string  | The last valid JSON object line that =stack admit= printed. |
| =outcome=   | string  | =admitted=, =refused= or =failed=.                |
| =unit=      | string  | The unit, as in =lines=.                          |
