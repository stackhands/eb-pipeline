* The site file

The site file holds everything =eb-pipeline= knows about a site: its scheduler, its node types, its paths, its modules and the tools it calls.
It is one file in Tom's Obvious Minimal Language (TOML), named by =--site=.
=eb-pipeline schema= prints the same keys with their types and defaults; =tests/docs.rs= checks this page against them.

** Format

- The file starts with =schema_version = 1= and =kind = "site"=.
- An unknown key, or a value of the wrong type, is an error.
  =check= lists every other problem of the file at once, one =ERROR [check] NAME: PROBLEM= line each, then =ERROR [main] -: N problem(s) in the site file=, and exits 2.
- An optional table that the file leaves out turns its phase off, and the plan and the result record the phase as =not configured=.
  So does =enabled = false= in the tables that have =enabled=.
- =site.name=, =site.project= and the name of each target hold letters, digits, =.=, =_= and =-= only.
  A target name is not =.= or =..=, since it names a directory.
- A value that holds the arguments of a command, such as =scheduler.launch= or a key of =[phase_defaults]=, is split into words as a shell splits them, with single and double quotes.
- The variables =EB_PIPELINE__SECTION__KEY= set values over the file before it is checked; [[file:environment.org][Environment variables]] describes them.

** Placeholders

=eb-pipeline= replaces a placeholder in braces in these keys, and =check= refuses any other placeholder in them.

|------------------------------------------------------------------------+-----------------------------------------------------------------------------------------------------------------|
| =scheduler.job_name_template=                                          | ={project}=, ={build}=, ={phase}=, ={target}=                                                                   |
| =filesystems.build_path=                                               | ={target}=, ={job_dir}=                                                                                         |
| =filesystems.tmp=                                                      | ={job_dir}=                                                                                                     |
| =filesystems.job_dir=                                                  | ={job}=, ={user}=                                                                                               |
| the entries of =filesystems.source_paths=, =rebuild.state_root=        | ={target}=                                                                                                      |
| =watch.state_dir=                                                      | ={target}=                                                                                                      |
| =targets.route.args=, the values of =targets.route.env=                | ={phase_dir}=, ={log_dir}=, ={work_dir}=, ={target}=, ={phase}=, ={runtime_root}=, ={shares_ro}=, ={shares_rw}= |
| the entries of =targets.route.shares_ro= and =targets.route.shares_rw= | ={phase_dir}=, ={log_dir}=, ={work_dir}=, ={target}=, ={phase}=                                                 |

| Placeholder      | Value                                                                                                 |
|------------------+-------------------------------------------------------------------------------------------------------|
| ={project}=      | =site.project=, else =site.name=                                                                      |
| ={build}=        | the build type                                                                                        |
| ={phase}=        | the phase that starts the command, such as =build= or =sources=                                       |
| ={target}=       | the name of the target                                                                                |
| ={log_dir}=      | the run's log directory, =LOG_ROOT/LOG_STAMP/TARGET=                                                  |
| ={phase_dir}=    | =LOG_DIR/PHASE=; when =args= or a share has it, the run makes the directory before the command starts |
| ={work_dir}=     | the target's =filesystems.build_path=                                                                 |
| ={runtime_root}= | =targets.route.runtime_root=, empty when it is unset                                                  |
| ={shares_ro}=    | the entries of =targets.route.shares_ro=, with their placeholders replaced, joined with =:=           |
| ={shares_rw}=    | the same for =targets.route.shares_rw=                                                                |
| ={job_dir}=      | =filesystems.job_dir=, with ={job}= and ={user}= replaced inside each job                             |
| ={job}=          | the Slurm job id, =SLURM_JOB_ID= inside the job                                                       |
| ={user}=         | the job's user, =SLURM_JOB_USER= inside the job, else =id -un=                                        |

*** {target} in paths

={target}= in =filesystems.build_path=, in an entry of =filesystems.source_paths= and in =rebuild.state_root= gives each target a path of its own.
=plan= and =explain= show the paths with the name in place.

- =build_path = "/scratch/alice/build/{target}"= gives each target an =EASYBUILD_BUILDPATH= of its own, and ={work_dir}= follows it.
- EasyBuild looks for a source in every entry of =source_paths= and downloads a missing one into the first, so =source_paths = ["/scratch/alice/sources/{target}", "/opt/site/sources"]= gives each target a download directory of its own and still finds the sources in =/opt/site/sources=.
- =state_root = "/opt/site/{target}/.eb-staged-rebuild"= gives each target an eb-staged-rebuild state root, and so a lock, of its own.

=check= refuses ={target}= in the other paths of =[filesystems]=, and a =state_root= with ={target}= when two targets that take staged rebuilds share a =software_root=: eb-staged-rebuild locks a live tree through its state root, so one tree takes one state root.

*** {job_dir} in paths

={job_dir}= in =filesystems.build_path= and =filesystems.tmp= puts them in a directory that each Slurm job has to itself on its node, which =filesystems.job_dir= names, such as the node-local mount that a prolog makes for each job:

#+begin_src toml
[filesystems]
job_dir = "/local/{user}.{job}"
build_path = "{job_dir}/build"
#+end_src

The job id and the user are known only inside the job.
=plan= and =explain= show =EASYBUILD_BUILDPATH= with ={job_dir}= in it, and =EB_PIPELINE_JOB_DIR= with ={job}= and ={user}=.
Each command that a job starts first runs a wrapper that replaces them, then checks that the directory exists and that the job can write to it, and otherwise exits 1 before the command starts.
So every job that a run or =watch= starts needs the directory, whatever its phase.
=check= refuses a =job_dir= without ={job}=, a =job_dir= with a scheduler other than =slurm=, ={job_dir}= in the other paths, and a route that still names the job directory when =build_path= has ={job_dir}=. That includes ={work_dir}= written directly, through ={runtime_root}=, or left in the route command: the route starts before the job.

** =[scheduler]=

| Key                 | Type            | Default                     | Meaning                                                                                                                                                 |
|---------------------+-----------------+-----------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------|
| =kind=              | string          | required                    | =slurm= starts each command through =launch=, with the launch arguments of its role; =local= starts it as it is, and the launch arguments are not used. |
| =launch=            | string          | =srun=                      | The launch command of =slurm=; not empty.                                                                                                               |
| =common_args=       | array of string | =[]=                        | Arguments of every launch line, after =launch= and before =--job-name=.                                                                                 |
| =env=               | table of string | ={}=                        | Variables set for every command; a variable that =eb-pipeline= sets itself replaces one of the same name.                                               |
| =job_name_template= | string          | ={project}-{build}-{phase}= | The job name each launch line passes as =--job-name=.                                                                                                   |

With =kind = "slurm"=, a command starts as =LAUNCH COMMON_ARGS --job-name=NAME ROLE_ARGS COMMAND=, where =ROLE_ARGS= are the launch arguments of the command's role and =COMMAND= starts with the module wrapper when there is one.
A role without launch arguments launches a bare =srun --job-name=NAME=, and inside an allocation =srun= then starts one task for each task of the allocation, so give each role a task count, such as =-N 1 --ntasks-per-node=1=.

*** =[targets.select]=

A build list can mark a line for some targets only, with an option of the line that names them.

| Key           | Type    | Default  | Meaning                                                                                                                                                           |
|---------------+---------+----------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =option=      | string  | required | The long option that carries the selection, with its leading dashes, such as =--only-targets=; a line carries it as =--only-targets=a,b= or =--only-targets a,b=. |
| =value=       | string  | required | The token of this target in the option's list; not empty, and without =separator=.                                                                                |
| =separator=   | string  | =,=      | What separates the tokens; not empty.                                                                                                                             |
| =when_absent= | string  | =all=    | =all= builds a line without the option on this target; =none= leaves it out.                                                                                      |
| =strip=       | boolean | =false=  | =true= removes the option from the line before =eb= gets it.                                                                                                      |

=plan= and =run= apply the selection to the whole list, or to each shard unit, and drop a unit left without lines.
With a selection, =run= writes the lines it keeps, in list order and with =strip= applied, to =LOG_DIR/selected-TARGET.list=, and passes that file to =stack shard --build-list=.
The plan and the result list the lines left out under =deselected=, and no status count includes them.
The separate-token form needs a value before the next option; otherwise =plan= and =run= exit 2 and name the list line.

** =[admission]=

Before each build unit, =eb-stack stack admit= checks that the unit fits in the free inodes of the scratch quota, and reserves them for the job.

| Key                 | Type    | Default        | Meaning                                                                                                                                                                                                                                                                      |
|---------------------+---------+----------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =enabled=           | boolean | =true=         | =false= turns the phase off.                                                                                                                                                                                                                                                 |
| =required=          | boolean | =false=        | =true= refuses the run with exit 78 when =quota_cmd= or =reservations= is missing; with =false=, the phase is then not configured.                                                                                                                                           |
| =quota_cmd=         | string  | none           | A shell command that prints the quota as JSON: =stack admit --quota-cmd=.                                                                                                                                                                                                    |

** =[resume]=

Set =enabled= to record the input identity of a run and to allow =run --resume-result FILE=.

** =[attest]=

Set =enabled= to hash the exact inputs of a finalized plan and append that record to an RFC 9162 sidecar log.
=plan= does this when it writes the plan.
=run= does it when the run starts, and not for =--dry-run=.
The record covers the build list, every easyconfig =eb-stack stack order --out= resolves, the easyblock class and patches those files name, the site file, the container image digest and the route receipt.
=verify= recomputes the record and checks the inclusion proof stored on the plan or the result.
Without the table, or with =enabled= false, a plan and a result are unchanged and =verify= is a usage error.

=log_dir= is a directory kept for this log.
=rfc9162-sidecar sync= records every file in it, so other files placed there become part of the log.
=key= is a PKCS#8 PEM file and =origin= is the checkpoint origin.
Each =trusted= line is =name+keyid+base64= for that origin, the text =rfc9162-sidecar verify-proof --trusted= takes.
=bin= is the =rfc9162-sidecar= program.
It is started as a subprocess and is not probed with =--version=.

=easyconfigs= are the trees given to =eb-stack stack order --easyconfigs=.
When that list is empty, =resume.easyconfigs= is used, then =shards.easyconfigs=.
=easyblocks= are directories searched for the Python file that defines each class.
A quoted =easyblock= assignment is read anywhere in the easyconfig, regardless of earlier assignments.
A class with no file is recorded with an empty path.
=patches= are extra directories searched, together with the easyconfig's own directory and the easyconfig trees, for a quoted name that ends in =.patch=.
Two files of the same name with different contents refuse the attestation.
=image_digest_env=, when set, must hold the container image digest or the attestation is refused.
The route receipt is the value of the target's =receipt_digest_env= when that variable is set, and otherwise empty; an empty receipt does not by itself refuse the attestation.

| Key                | Type            | Default           | Meaning                                                                                                                                                          |
|--------------------+-----------------+-------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =enabled=          | boolean         | =false=           | =true= appends an input record on =plan= and on =run=. =false= records nothing, and =verify= is refused.                                                         |
| =log_dir=          | string          | none              | Directory of the sidecar log. Required when enabled. A directory kept for this log: =rfc9162-sidecar sync= records every file in it.                            |
| =key=              | string          | none              | PKCS#8 PEM file passed to =rfc9162-sidecar snapshot --key=. Required when enabled.                                                                               |
| =origin=           | string          | none              | Checkpoint origin passed to =rfc9162-sidecar snapshot --origin=. Required when enabled. A trusted line names this origin.                                       |
| =trusted=          | array of string | =[]=              | Verifier lines =name+keyid+base64= passed to =rfc9162-sidecar verify-proof --trusted=. At least one when enabled.                                                |
| =bin=              | string          | =rfc9162-sidecar= | The =rfc9162-sidecar= program. It is not probed with =--version=.                                                                                                |
| =image_digest_env= | string          | none              | Environment variable that holds the container image digest. When set, an empty value refuses the attestation.                                                   |
| =easyconfigs=      | array of string | =[]=              | Easyconfig trees for =eb-stack stack order --easyconfigs=. When empty, =resume.easyconfigs= is used, then =shards.easyconfigs=.                                  |
| =easyblocks=       | array of string | =[]=              | Directories searched for the Python file that defines each resolved easyblock class. A class with no file is recorded with an empty path.                       |
| =patches=          | array of string | =[]=              | Extra directories searched, with the easyconfig's directory and the easyconfig trees, for a patch a resolved easyconfig names.                                  |

entry and =easyconfigs= here or under =[shards]=.

interpret their dependency or recipe logic.
After every fetch succeeds, it copies regular files under the source paths
and every configured asset into =DIR/objects/sha256=, indexes the planner
outputs there too, and writes =DIR/manifest.json=.
The directory must not exist; a rerun therefore cannot overwrite or mix an
earlier valid bundle.

** =[rebuild]=

A line goes through =eb-staged-rebuild run= instead of =eb= when all three hold:

1. the target takes staged rebuilds: its =staged=, else =rebuild.staged=, is =true=;
2. the line carries =--rebuild=, =-f= or =--force= as a whole option, which =--force-download= and =--rebuild-from-scratch= are not;
3. the line's module is installed under the target's =modules_root=.

Otherwise the line builds with =eb=; on a target that takes staged rebuilds, a line that has the option but no installed module gets a note in the plan and a =WARN= line in the run.

A run checks the URL in the variable of =webhook_env= the same way when it ends.
A run that writes no summary, such as =run --dry-run=, sends nothing.
A POST that cannot start, fails or runs out of time is a =WARN= line, and the run exits as it would have without the table; [[file:run-summary.org][The run summary]] shows the lines that a run writes.

** =[sbom]=

With the table, a clean =run= starts =eb-stack stack sbom --lock LOCK --out LOG_ROOT/LOG_STAMP/sbom.cdx.json= and keeps that file beside =summary.json=.
A build that did not exit 0 does not start it, and neither does =run --dry-run=.
A command that cannot be started, or that exits with a status other than 0, fails the run with that status and leaves no =sbom.cdx.json=.
When a signal ends the command, the run uses =128 + SIGNAL=, such as 143 for =SIGTERM=.
eb-stack reads the lock and writes the document; eb-pipeline does not compute a bill of materials of its own.

| Key       | Type    | Default | Meaning                                                                                                        |
|-----------+---------+---------+----------------------------------------------------------------------------------------------------------------|
| =enabled= | boolean | =true=  | =false= stores nothing.                                                                                        |
| =lock=    | string  | none    | The lock file given to =eb-stack stack sbom --lock=; required when enabled, and an absolute path.             |

** =[watch]=

With the table, each =run= records what every install it builds was built against in EESSI, with the EESSI modules that eb-stack says the install depends on, and =watch= rebuilds the recorded installs that a change of EESSI reaches; [[file:watch.org][The watch state and plan]] says how.

| Key              | Type            | Default                                      | Meaning                                                                                                                                                                                                                                    |
|------------------+-----------------+----------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =enabled=        | boolean         | =true=                                       | =false= records nothing, and =watch= exits 78.                                                                                                                                                                                             |
| =state_dir=      | string          | =<install prefix>/.eb-pipeline-watch=        | The directory of =TARGET.json=, the record of the target, and of its lock; ={target}= is the name of the target.                                                                                                                           |
| =repository=     | string          | =EESSI_CVMFS_REPO=                           | The directory whose CVMFS =user.revision= attribute a record reads, in place of the =EESSI_CVMFS_REPO= of the module environment.                                                                                                          |
| =modules_dirs=   | array of string | =EESSI_MODULEPATH=, =EESSI_MODULEPATH_ACCEL= | The EESSI module trees, in order, in place of the ones that the module environment sets.                                                                                                                                                   |
| =easyconfigs=    | array of string | =$EBROOTEASYBUILD/easybuild/easyconfigs=     | The easyconfig trees that =watch= gives =eb-stack stack shard= under those of EESSI and of the target, in which it finds the easyconfig of an EESSI module that vanished; the default reads =EBROOTEASYBUILD= from the module environment. |
| =rebuild_review= | boolean         | =true=                                       | Whether =watch= rebuilds an install when a dependency that =eb-stack rebuild-set= classes =review= changed or vanished; =false= keeps the install, with a =WARN= line.                                                                     |
| =abi_drift=      | table           | none                                         | Opt-in host ABI drift checks for =watch=. Changed fields map to provider easyconfigs, which =watch= gives to =eb-stack rebuild-set --changed=.                                               |

The paths are absolute, which =check= checks.
The install prefix is the =site_prefix= of the target, else =filesystems.install_root=.
A record that fails is a =WARN= line, and the run exits as it would have without the table.

** =[watch.abi_drift]=

With the table and =enabled = true=, =watch= runs each command of =probe= in the target environment, trims each command's standard output, and compares the resulting field map with the baseline in the watch state.
For each field whose value changed, =watch= reads =providers.FIELD= and passes those easyconfig file names to =eb-stack rebuild-set --changed=.

| Key         | Type                     | Default | Meaning                                                                                                                                             |
|-------------+--------------------------+---------+-----------------------------------------------------------------------------------------------------------------------------------------------------|
| =enabled=   | boolean                  | =false= | =true= enables ABI drift checks; =false= leaves =watch= byte-identical to earlier behavior.                                                       |
| =probe=     | table of string          | ={}=    | One shell command per field; each command's trimmed standard output is the field value. Required when enabled.                                    |
| =providers= | table of array of string | ={}=    | One provider easyconfig file-name list per field. A changed field with no providers is refused, as =watch= cannot compute a selective rebuild set. |
